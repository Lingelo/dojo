# Changelog

Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions: [SemVer](https://semver.org/).

## [1.1.0] - 2026-11-11

### Changed
- **agent-skills is embedded in Kaizen: one plugin to install.** The copy moves from
  `plugins/agent-skills/` to `plugins/kaizen/agent-skills/` (still unmodified, still updated by pull
  request). Its skills load as `kaizen:<skill>` (`plugin.json` `skills`), its personas as
  `kaizen:code-reviewer`, `kaizen:security-auditor`, `kaizen:test-engineer`,
  `kaizen:web-performance-auditor` (`agents/`, generated by `scripts/aliases.mjs` like the commands).
  `agent-skills@dojo` leaves the marketplace; `install settings` declares `kaizen@dojo` only.
- **`kaizen doctor`'s `agent_skills` check** shows the embedded version, and warns when
  `agent-skills@dojo` is still enabled (its skills would load twice).

## [1.0.0] - 2026-11-11

Kaizen is the engine around Addy Osmani's [agent-skills](https://github.com/addyosmani/agent-skills),
shipped next to it in the dojo marketplace: agent-skills does the work (spec, plan, build, test, review,
ship), Kaizen adds what it does not do — gates the agent cannot talk its way past, memory between
cycles, PR follow-up and measurement.

### Added
- **agent-skills' commands under `/kaizen:`**: `spec`, `plan`, `build`, `test`, `review`, `ship`,
  `constraints`, `code-simplify`, `webperf` — exact copies of its commands, generated by
  `scripts/aliases.mjs` and regenerated when agent-skills is synced.
- **Entry points onto agent-skills' skills that have no command**, generated by the same script:
  `/kaizen:ideate` (`interview-me`, `idea-refine`), `/kaizen:debug` (`debugging-and-error-recovery`),
  `/kaizen:adr` (`documentation-and-adrs`), `/kaizen:security` (`security-and-hardening`),
  `/kaizen:doubt` (`doubt-driven-development`), `/kaizen:migrate` (`deprecation-and-migration`).
- **Four skills** in agent-skills' anatomy: `/kaizen:setup` (configuration, both plugins declared,
  doctor, next command), `/kaizen:learn` (capture, harvest, prune), `/kaizen:metrics` (DORA approximated,
  learnings reuse, friction, cost per work item), `/kaizen:watch` (a PR followed to "looks ready").
- **Quality gate**: as soon as a session edits code, the turn cannot end while the checks are red
  (`gate.max_blocks` at most).
- **Review before push**: agent-skills' review records itself (its review skill or its `code-reviewer`
  persona, verdict read from what it wrote); an unreviewed push is stopped once, Claude asks, and only
  the user lets it out in Claude Code's own prompt.
- **No secret committed**: about thirty key and token formats, `--no-verify` refused, in every repository.
- **Learnings read back**: one lesson per file in `docs/learnings/`, added to Claude's context when
  `SPEC.md` or `tasks/` are written, or when a file a learning names in `files:` is edited.
- **Cost per work item**: every turn's tokens charged to the branch's Jira key (else the branch), for
  `kaizen cost` and `/kaizen:metrics`.
- **`kaizen` CLI** (Node ≥ 18, no dependency): `status`, `doctor`, `verify`, `gate`, `review`, `secrets`,
  `learnings`, `metrics`, `cost`, `pr`, `install settings`, `init`, `config`, `detect`, `root`.
- **Documentation**: getting started, one guide per skill, concepts, reference, troubleshooting,
  positioning.
